    Worksheet Growth Patterns
    

    Objectives

    • Given a visual pattern, I can draw the next case, record the number of shapes in a table, describe in my own words how the pattern grows, and plot the counts on a graph.
      🔗
    🔗
    For each pattern below: draw Case 4, complete the table, describe in your own words how the pattern grows, then plot the number of shapes for each case as a point on the grid.
    🔗

    1. Pattern 1.

    The first three cases of a pattern of squares are shown below. Each case is a solid square of tiles.
    🔗
    
    A sequence of solid squares built from square tiles. Case 1 is a single tile. Case 2 is two tiles wide and two tiles tall, four tiles in all. Case 3 is three tiles wide and three tiles tall, nine tiles in all. Case 4 is shown as an empty outline four tiles wide and four tiles tall.
    🔗

    (a)

    Draw Case 4.
    🔗
    🔗

    (b)

    Count the shapes in each case and complete the table.
    🔗
    Case (\(n\)) \(1\) \(2\) \(3\) \(4\) \(5\)
    Shapes \(1\) \(4\) \(9\)
    Answer.
    The counts are \(1, 4, 9, 16, 25\text{.}\)
    🔗
    🔗
    🔗

    (c)

    In your own words, describe how the pattern grows from one case to the next.
    🔗
    Answer.
    Case \(n\) is a square that is \(n\) tiles wide and \(n\) tiles tall, so the number of tiles is \(n\) times \(n\text{.}\) Going from one case to the next, a new row is added along the bottom and a new column along the side, so the number of tiles added grows each time: \(3\) tiles from Case 1 to Case 2, then \(5\text{,}\) then \(7\text{,}\) then \(9\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Plot the number of shapes for each case as a point on the grid below.
    🔗
    
    A blank coordinate grid. The horizontal axis is labeled Case number and is marked at each whole number from 1 to 7. The vertical axis is labeled Number of shapes and is marked every 2 units from 2 to 26.
    🔗
    Answer.
    The points are \((1,1)\text{,}\) \((2,4)\text{,}\) \((3,9)\text{,}\) \((4,16)\text{,}\) and \((5,25)\text{.}\) They do not fall in a straight line; the points climb more steeply with each case.
    🔗
    🔗
    🔗
    🔗

    2. Pattern 2.

    The first three cases of a pattern are shown below. Each case is a staircase, built one row at a time.
    🔗
    
    A sequence of staircases built from square tiles. Case 1 is a single tile. Case 2 has a bottom row of two tiles with one tile above the left tile, three tiles in all. Case 3 has a bottom row of three tiles, a row of two above it, and a single tile on top, six tiles in all. Case 4 is shown as an empty outline four tiles wide and four tiles tall.
    🔗

    (a)

    Draw Case 4.
    🔗
    🔗

    (b)

    Count the shapes in each case and complete the table.
    🔗
    Case (\(n\)) \(1\) \(2\) \(3\) \(4\) \(5\)
    Shapes \(1\) \(3\) \(6\)
    Answer.
    The counts are \(1, 3, 6, 10, 15\text{.}\)
    🔗
    🔗
    🔗

    (c)

    In your own words, describe how the pattern grows from one case to the next.
    🔗
    Answer.
    Each case adds one more row along the bottom, and that new row has one more tile than the row that was on the bottom before. So Case 2 adds \(2\) tiles, Case 3 adds \(3\) tiles, Case 4 adds \(4\) tiles, and Case 5 adds \(5\) tiles. The number of tiles added grows by one each time.
    🔗
    🔗
    🔗

    (d)

    Plot the number of shapes for each case as a point on the grid below.
    🔗
    
    A blank coordinate grid. The horizontal axis is labeled Case number and is marked at each whole number from 1 to 7. The vertical axis is labeled Number of shapes and is marked every 2 units from 2 to 16.
    🔗
    Answer.
    The points are \((1,1)\text{,}\) \((2,3)\text{,}\) \((3,6)\text{,}\) \((4,10)\text{,}\) and \((5,15)\text{.}\) They do not fall in a straight line; each step up is a little larger than the one before.
    🔗
    🔗
    🔗
    🔗

    3. Pattern 3.

    The first three cases of a pattern are shown below. Each case is a single row of tiles.
    🔗
    
    A sequence of single rows built from square tiles. Case 1 is one tile. Case 2 is a row of two tiles. Case 3 is a row of four tiles. Case 4 is shown as an empty outline eight tiles long.
    🔗

    (a)

    Draw Case 4.
    🔗
    🔗

    (b)

    Count the shapes in each case and complete the table.
    🔗
    Case (\(n\)) \(1\) \(2\) \(3\) \(4\) \(5\)
    Shapes \(1\) \(2\) \(4\)
    Answer.
    The counts are \(1, 2, 4, 8, 16\text{.}\)
    🔗
    🔗
    🔗

    (c)

    In your own words, describe how the pattern grows from one case to the next.
    🔗
    Answer.
    Each case has twice as many tiles as the case before it. The row doubles in length every time, so the number of tiles added also doubles: \(1\) tile is added, then \(2\text{,}\) then \(4\text{,}\) then \(8\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Plot the number of shapes for each case as a point on the grid below.
    🔗
    
    A blank coordinate grid. The horizontal axis is labeled Case number and is marked at each whole number from 1 to 7. The vertical axis is labeled Number of shapes and is marked every 2 units from 2 to 16.
    🔗
    Answer.
    The points are \((1,1)\text{,}\) \((2,2)\text{,}\) \((3,4)\text{,}\) \((4,8)\text{,}\) and \((5,16)\text{.}\) They do not fall in a straight line; the points stay low at first and then climb very quickly.
    🔗
    🔗
    🔗
    🔗

    4. Pattern 4.

    The first three cases of a pattern are shown below. Each case is a plus sign with four arms.
    🔗
    
    A sequence of plus signs built from square tiles. Case 1 is a center tile with one tile out from each of the four sides, five tiles in all. Case 2 has arms two tiles long, nine tiles in all. Case 3 has arms three tiles long, thirteen tiles in all. Case 4 is shown as an empty outline nine tiles wide and nine tiles tall.
    🔗

    (a)

    Draw Case 4.
    🔗
    🔗

    (b)

    Count the shapes in each case and complete the table.
    🔗
    Case (\(n\)) \(1\) \(2\) \(3\) \(4\) \(5\)
    Shapes \(5\) \(9\) \(13\)
    Answer.
    The counts are \(5, 9, 13, 17, 21\text{.}\)
    🔗
    🔗
    🔗

    (c)

    In your own words, describe how the pattern grows from one case to the next.
    🔗
    Answer.
    Each case adds one tile to the end of each of the four arms, so \(4\) tiles are added every time. The center tile stays the same throughout.
    🔗
    🔗
    🔗

    (d)

    Plot the number of shapes for each case as a point on the grid below.
    🔗
    
    A blank coordinate grid. The horizontal axis is labeled Case number and is marked at each whole number from 1 to 7. The vertical axis is labeled Number of shapes and is marked every 2 units from 2 to 22.
    🔗
    Answer.
    The points are \((1,5)\text{,}\) \((2,9)\text{,}\) \((3,13)\text{,}\) \((4,17)\text{,}\) and \((5,21)\text{.}\) These points do fall in a straight line, since the same number of tiles is added each time.
    🔗
    🔗
    🔗

    (e)

    How many shapes would be in Case 10? Explain how you figured it out.
    🔗
    Answer.
    There would be \(41\) shapes. Case 5 has \(21\) tiles, and each case after that adds \(4\) more, so Cases 6 through 10 have \(25, 29, 33, 37\text{,}\) and \(41\) tiles. Another way to see it: each arm in Case 10 is \(10\) tiles long, which accounts for \(4 \cdot 10 = 40\) tiles, plus the \(1\) center tile the arms share, giving \(41\text{.}\)
    🔗
